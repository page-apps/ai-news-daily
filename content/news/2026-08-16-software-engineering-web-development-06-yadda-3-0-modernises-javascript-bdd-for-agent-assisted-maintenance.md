## Summary

Yadda 3 removes browser bundling and obsolete integrations, adopts node:test, Biome and lefthook, adds Playwright and Puppeteer examples, and now ships TypeScript definitions. Its maintainer says Claude Code with Opus 4.8 performed most of the modernisation while a comprehensive test suite and separated implementation/test changes supplied the main constraints.

## Why it matters

The release is a concrete example of maintainers using an agent for broad repository modernisation while preserving tests as an external check on behavioural correctness.
