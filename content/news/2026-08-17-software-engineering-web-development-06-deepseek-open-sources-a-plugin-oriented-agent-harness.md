## Summary

The DeepSeek Harness is built on the Cordis framework and provides components for context handling, tool use, orchestration, state, permissions, and error management. It also supports append-only session logs that can be inspected, forked, searched, and replayed.

## Why it matters

The release makes agent orchestration itself a reusable developer surface and highlights that harness architecture, not only model quality, affects reliability, cost, and long-running coding workflows.
