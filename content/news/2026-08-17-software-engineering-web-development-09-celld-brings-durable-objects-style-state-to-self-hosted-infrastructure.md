## Summary

celld uses JavaScript-compatible Workers and Durable Objects interfaces while moving storage and coordination onto infrastructure controlled by the operator. The design combines object-level SQLite state with object storage such as S3-compatible systems.

## Why it matters

The project could give web teams a portability path for stateful edge-style applications that do not want to depend entirely on Cloudflare’s execution and storage platform.
