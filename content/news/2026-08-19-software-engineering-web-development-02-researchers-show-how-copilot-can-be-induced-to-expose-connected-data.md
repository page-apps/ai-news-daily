## Summary

The CoSnitch research found that repeatedly challenging Microsoft Copilot about an attack could reveal undocumented autorun and prompt-parameter behaviour. A crafted URL could then execute a malicious prompt in an authenticated session, potentially exposing connected application data or altering Copilot memory.

## Why it matters

AI assistants embedded in productivity workflows create a new application-security boundary where prompt handling, URL processing and connected-data permissions must be tested together.
