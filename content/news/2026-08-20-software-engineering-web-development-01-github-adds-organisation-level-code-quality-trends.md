## Summary

The dashboard now plots open findings over 7-, 14-, or 30-day periods and ranks repositories by changes. It respects existing filters and is available to eligible GitHub Enterprise Cloud and Team organisations using Code Quality, but not GitHub Enterprise Server.

## Why it matters

This gives engineering and security teams a time-series view of remediation progress across repositories.
