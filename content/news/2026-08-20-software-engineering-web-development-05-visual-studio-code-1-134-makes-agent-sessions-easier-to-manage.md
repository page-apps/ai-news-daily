## Summary

The release lets the same agent session connect to multiple VS Code windows through the Agent Host Protocol and aligns its Copilot agent with Copilot CLI and other Copilot products. It also adds side-by-side chat groups, a prompt timeline with file-change counts, full-text conversation search, and local HTML preview in the integrated browser.

## Why it matters

VS Code is moving agentic development towards persistent, inspectable, multi-window workflows.
