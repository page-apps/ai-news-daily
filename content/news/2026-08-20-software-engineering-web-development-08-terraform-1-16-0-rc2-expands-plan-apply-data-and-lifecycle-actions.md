## Summary

The release candidate adds provider-private data preservation across plan and apply, a store block in terraform_data for ephemeral and sensitive values, import blocks inside modules, and resource-action failure modes. It also adds JSON output for state show and workspace list, Mermaid output for graph, and destroy=false lifecycle support.

The changes give infrastructure teams more precise state handling, automation-friendly output, and control over resource lifecycles.
