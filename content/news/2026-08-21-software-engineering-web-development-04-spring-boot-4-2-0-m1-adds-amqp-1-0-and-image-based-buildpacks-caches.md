## Summary

Spring Boot 4.2.0-M1 adds generic AMQP 1.0 and RabbitMQ AMQP 1.0 support, and lets Cloud Native Buildpacks publish and restore build caches through an image registry. Its release notes also change forwarded-header configuration and stop test MeterRegistry beans entering Micrometer's global registry by default.

Teams evaluating the next Spring baseline face meaningful changes in messaging, deployment efficiency, HTTP proxy handling and observability.
