## Summary

The beta moves a conversation, attached images and an optional follow-up command into a Cline Cloud workspace that continues after the desktop app closes. It checks that the repository, branch and commit are pushed before handoff, adds Cloud to the existing Local/Remote menu, and restores drafts and attachments after interrupted transfers.

## Why it matters

It turns a local agent session into a resumable cloud workload without discarding its working context.
