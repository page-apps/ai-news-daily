## Summary

The remote-control command no longer fails when its preferred port is occupied; it now requests a free operating-system port. New environment variables can hide the logo or disable escape-sequence optimisations for screen readers, recordings, and constrained terminals.

## Why it matters

These changes make agent control more reliable in automated environments and more usable in accessibility-sensitive or non-interactive workflows.
