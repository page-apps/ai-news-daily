## Summary

The public beta is available for macOS, Windows and Linux and supports GitHub, GitLab and Bitbucket. Zide Assist can use Claude, Codex and Gemini, while the application is built with Tauri and Rust rather than as a browser wrapper.

## Why it matters

Zide treats coding agents as participants in the issue-to-merge workflow, targeting the context switching and provider lock-in created by separate editors, trackers and AI interfaces.
