## Summary

Codex CLI 0.150 lets users reference other tasks with @ mentions and ask agents to read, create or message tasks from the terminal; it also adds a copy picker, automatic task titles, clickable Markdown links and interrupt hooks. The release says untrusted projects no longer provide project-level AGENTS.md instructions, managed deny-read rules persist after permission changes, and app-server diagnostics improve credential redaction.

## Why it matters

This moves terminal coding agents towards coordinated multi-task work while making repository trust and interruption boundaries more explicit.
