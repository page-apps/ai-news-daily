## Summary

VS Code 1.135 can show recent Copilot or Claude agent sessions created in other applications and let users continue them in VS Code. It also introduces experimental Rubber Duck second opinions, a default single-pane Agents layout and per-model input, cached-input and output token details.

## Why it matters

This reduces the boundary between agent products and gives developers a clearer place to review work and usage.
