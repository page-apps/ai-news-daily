## Summary

Operant AI launched Semantic Firewall to allow, block or redact prompts, tool calls, commands and data payloads in real time. Its Code Intent Guard is aimed at package installation, MCP and tool setup, shell commands, prompt injection, privilege escalation and hidden directives.

## Why it matters
