## Summary

RunMyJobs 2026.3 added a generally available MCP server with more than 50 production-ready tools, native AWS S3, EventBridge and Glue connectivity, and support for agent-to-agent workflows. Redwood also introduced Agent Studio, Workflow Builder and an Operations Agent as technology previews with audit and governance controls.

## Why it matters

Enterprise agents need controlled access to dependable operational workflows, and orchestration systems are becoming a key integration layer between agents and production infrastructure.
