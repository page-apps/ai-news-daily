## Summary

Angular ESLint 22.2 adds an allowExplicitOnPush option that can automatically remove explicit OnPush declarations when a project disallows them. It also reports Angular major-version mismatches at runtime and adds template rules covering duplicate metadata arrays, ARIA validity and static string properties.

## Why it matters

These checks move architectural and accessibility conventions into repeatable CI enforcement for Angular teams.
