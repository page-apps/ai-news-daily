## Summary

React Hook Form 7.87 adds a shouldTouch option to trigger() and an OpaqueTypes registry for leaf types that should not be recursively analysed. The release also fixes controller change handling, hidden Activity subtree watching, resetField validity and React Server declaration resolution in Next.js builds.

## Why it matters

The changes target two recurring sources of form-library friction: excessive type computation and inconsistent state updates in modern React rendering environments.
