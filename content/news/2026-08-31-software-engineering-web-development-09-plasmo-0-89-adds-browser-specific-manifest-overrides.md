## Summary

Plasmo 0.89 adds an overrides key for browser-specific manifest configuration and logs the selected target during plasmo build and plasmo dev. The release also documents zip output and CLI argument values more clearly.

## Why it matters

Browser-specific manifest control simplifies multi-browser extension builds and makes target selection easier to diagnose in local and automated environments.
