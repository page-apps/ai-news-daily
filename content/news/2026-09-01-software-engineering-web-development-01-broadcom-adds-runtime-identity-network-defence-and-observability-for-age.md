## Summary

AgentMinder binds agent authority to declared missions, intents, tools and resources, enforcing least-privilege policy at each tool invocation. VMware vDefend and Avi add MCP and LLM discovery, shadow-AI monitoring, anomalous-traffic detection, malicious-execution blocking and OpenTelemetry auditability.

## Why it matters

This moves agent security towards runtime identity, network enforcement and traceability rather than relying only on model guardrails.
