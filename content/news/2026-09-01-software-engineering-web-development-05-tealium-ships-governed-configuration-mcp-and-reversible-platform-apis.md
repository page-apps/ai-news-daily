The Configuration MCP lets compatible agents create and modify audiences, attributes, enrichments and activation workflows, with changes held as drafts until review. The Developer Portal adds authenticated, versioned, validated and reversible workflows with access controls and rollback support.

This is a concrete move from agents merely reading business context to making controlled changes in a production data platform.
