## Summary

Enterprise Personal Agent Access, delivered through PingOne Privilege, associates agent sessions with the user and device behind them and applies allow, deny, logging and approval policies at runtime. Ping said the controls cover desktop assistants such as Claude and coding agents such as Claude Code, including commit attribution without long-lived credentials.

## Why it matters

Agent identity and provenance are becoming prerequisites for safely connecting coding agents to repositories, infrastructure, APIs and other privileged developer resources.
