## Summary

Cline Desktop 0.0.22 can scan local stores and import selected Claude Code, Codex and OpenCode conversations as fully resumable Cline sessions. The release also folds scheduled runs into the sidebar and adds workflow, tool-call and marketplace fixes.

## Why it matters

Session history is becoming portable working state rather than disposable chat. Cross-agent import lowers switching costs and creates pressure for common transcript, tool-state and checkpoint formats.
