## Summary

GitHub made enterprise-managed default-model settings available for Copilot Business and Enterprise. Administrators can set the model used for new conversations and map different defaults to enterprise teams through configuration, including across the Copilot app, CLI and VS Code.

## Why it matters

Model selection becomes an organisation-level policy rather than an individual developer preference. This enables more consistent capability, cost and rollout management across engineering teams.
