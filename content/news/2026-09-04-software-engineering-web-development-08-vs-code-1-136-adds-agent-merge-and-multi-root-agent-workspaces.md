## Summary

VS Code 1.136 introduces Agent Merge in preview, allowing an agent to address review feedback, failed checks and conflicts and rerun workflows until a change is ready to merge. It also adds experimental multi-root workspaces for Copilot and Claude sessions and expands agent-session hierarchy, notifications and workspace resolution.

## Why it matters

The release positions the IDE agent inside the full pull-request rework loop rather than only code generation. Multi-root support also improves the ability to operate across related repositories and workspace components.
