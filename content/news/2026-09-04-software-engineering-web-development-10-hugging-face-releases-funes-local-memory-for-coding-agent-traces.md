## Summary

Hugging Face introduced Funes, an open-source tool that indexes traces from Claude Code, Codex, pi and Hermes into a local memory or dataset. It can retrieve source passages instead of generated summaries and optionally share a dataset across machines or agents through Hugging Face.

## Why it matters

The project points toward portable, user-owned memory for coding agents rather than isolated session histories. Source-based retrieval also offers a more inspectable foundation for reusing prior engineering context.
