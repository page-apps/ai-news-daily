## Summary

The preview adds Web Shell workflow visualisation, live subagent status, a session resource catalogue, worktree-isolated named tasks and session-turn navigation. It also introduces mandatory conversation writer leases and workspace-scoped skills runtime.

## Why it matters

These changes make long-running, concurrent coding-agent work easier to inspect, control and recover without treating the terminal session as the only source of state.
