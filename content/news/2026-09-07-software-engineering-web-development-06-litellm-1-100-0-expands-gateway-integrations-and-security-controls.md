## Summary

The release adds per-team New Relic trace routing, Grounding with Bing Search, native Vertex AI Interactions API support and Entra ID/OAuth authentication across Azure AI Foundry routes. It also introduces vector-store upload security controls and updates MCP, A2A, routing, cost and provider handling.

## Why it matters

AI gateways increasingly sit between applications and multiple model providers, so their authentication, tracing, cost accounting and content-ingestion controls directly shape production engineering risk.
