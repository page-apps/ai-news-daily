## Summary

APM 0.29.1 adds support for catalog-only marketplace plugins and improves diagnostics for malformed executable trust configuration. It also fixes staging cleanup, plugin hooks during reinstall, private cache authentication, deterministic lockfiles and MCP dependency resolution.

## Why it matters

Agent configuration is becoming a dependency-management problem; deterministic installs and explicit trust diagnostics are prerequisites for safely sharing agent skills and plugins across teams.
