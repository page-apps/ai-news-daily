## Summary

Open Code Review 1.11.6 adds first-class controls for effort, maximum token budget and LLM reasoning effort, alongside live review progress. It also adds OCaml and ReasonML allowlists, line numbering in the existing-code viewer and signal-forwarding fixes.

## Why it matters

Budget and effort controls make LLM code review more governable, helping teams balance review depth, latency and inference cost in automated pipelines.
