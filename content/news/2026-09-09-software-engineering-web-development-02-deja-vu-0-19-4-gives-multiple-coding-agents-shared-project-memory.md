## Summary

Déjà Vu 0.19.4 connects shared memory to 23 agent harnesses, including VS Code Copilot Chat, Amp, Prime Agent, Cline, Qwen Code and OpenClaw. The release adds session digests, per-prompt recall, compaction-aware forgetting and same-turn repair context for failed commands.

## Why it matters

Cross-agent memory turns context retention into a reusable developer-infrastructure layer rather than a feature locked to one coding assistant.
