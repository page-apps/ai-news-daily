## Summary

The release lets approved Web Shell goals start automatically, adds a peer endpoint for external cross-session messaging and introduces limits for goal turns and active minutes. It also routes scheduled Web Shell runs to configured models and session groups, while removing configurable message-prefix filtering from channels.

## Why it matters

The update moves Qwen Code towards coordinated, bounded agent execution across persistent sessions and web-based workflows.
