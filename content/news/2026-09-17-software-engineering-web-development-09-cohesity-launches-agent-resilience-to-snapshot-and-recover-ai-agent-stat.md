## Summary

Agent Resilience discovers and protects agent memory and configuration with point-in-time recovery, immutable backups and clean-room recovery patterns. It also maps connected applications, databases and other services so teams can restore both an agent and resources it changed; availability is initially limited to select customers.

## Why it matters

As agents gain permission to modify production systems, rollback and dependency-aware recovery become operational requirements alongside monitoring and access controls.
