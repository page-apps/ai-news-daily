## Summary

Node.js 26.9 adds Web Workers support, a generic MAC API, OpenSSL provider cipher and hash discovery, default FFI support and a new `node:bench` implementation. It also extends `perf_hooks` with meanCI and CBOR operations and introduces an experimental DTLS API alongside broader crypto, HTTP, filesystem and permission changes.

## Why it matters

The release changes the capabilities available to server-side JavaScript applications and makes more runtime functionality accessible without external packages or custom native integrations.
