## Summary

Studio Code now records a chosen visual direction in DESIGN.md and uses it to populate theme files, alongside design-selection previews. The release also adds capability tiers, multi-select agent questions, prompt-box answers, theme validation after writes, batched file edits, smaller screenshots and AI-credit warnings.

## Why it matters

Persistent design context and post-write validation address two major weaknesses of AI website generation: visual drift and unreliable edits.
