## Summary

The release adds GPT-6 Sol, GPT-6 Luna and Claude Opus 5.5 to the model picker when available, and reads Claude Code rule files as custom instructions. It also improves MCP OAuth scope handling, tolerates invalid neighbouring MCP entries, follows repository pull-request templates, and strengthens sandbox and session behaviour.

## Why it matters

The CLI is becoming a common control surface for multiple coding-agent models, so its instruction, MCP and review-process compatibility has broad workflow consequences.
