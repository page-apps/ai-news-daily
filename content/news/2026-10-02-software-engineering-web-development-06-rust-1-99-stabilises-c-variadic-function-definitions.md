## Summary

The release makes it possible to define C-variadic functions in stable Rust and stabilises the associated unsafe-naked-function capability. It also adds the raw-borrow lint and extends panic analysis for zero-sized chunks and windows.

## Why it matters

Stable variadic-function support improves Rust interoperability with low-level C APIs and systems code without requiring nightly toolchains.
