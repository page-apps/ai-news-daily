## Summary

The release declares mid-conversation support in model profiles across the core, Anthropic and OpenAI integrations. This gives applications structured metadata for deciding whether a provider can safely accept model or configuration changes during an active exchange.

## Why it matters

Explicit capability metadata reduces provider-specific assumptions in agent orchestration and makes multi-provider conversation handling more predictable.
