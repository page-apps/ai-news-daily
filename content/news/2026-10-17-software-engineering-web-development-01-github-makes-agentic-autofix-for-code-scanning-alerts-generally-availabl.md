## Summary

The feature explores relevant files, iterates on proposed fixes, and validates remediation by rerunning CodeQL before creating a draft pull request. It is available to GitHub Code Security and Advanced Security customers on Enterprise Cloud, with AI Credits and Actions-minute usage.

## Why it matters

This turns vulnerability remediation into an agent-assisted, reviewable CI/CD workflow, although CodeQL validation and human review remain necessary.
