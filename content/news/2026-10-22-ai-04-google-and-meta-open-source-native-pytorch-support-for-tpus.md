## Summary

TorchTPU lets existing PyTorch workloads run on Google TPUs with minimal code changes and supports training, serving and deployment tools including vLLM and SGLang. The release is intended to make TPUs a more practical alternative to GPU-centric AI software stacks.

## Why it matters

Reducing software friction is one of the strongest ways for alternative accelerators to challenge Nvidia’s ecosystem advantage.
